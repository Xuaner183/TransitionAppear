# 使用说明

运行 `pnpm install --frozen-lockfile`、`pnpm generate`、`pnpm preview`，访问 http://127.0.0.1:4173/。完整步骤见 README，提交方式见 ISSUE.md。

已验证安装、静态生成、预览首页 HTTP 200 及生成节点结构。补充纯 Vue + Happy DOM 生产水合诊断中，静态组仍保留在 template 内，条件组正常解包。当前真实浏览器自动化不可用，尚未完成独立复现项目的浏览器实测，提交前应人工确认并填写浏览器版本。

初次安装因 pnpm 阻止 esbuild 构建脚本而非零退出，已通过 pnpm-workspace.yaml 的 allowBuilds 显式允许 esbuild，重装成功。Nuxt preview 面向服务端产物，已改用 Vite 预览静态目录。最终生成保留 Nitro cache-driver 外部化警告，未阻止生成。

本地 generate.log、install.log 与 preview.log 属于验证过程日志，均被忽略，不纳入复现仓库。
